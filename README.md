# tabledex-landing-page
Esta Landing Page foi desenvolvida como parte de um projeto acadêmico. O objetivo é atuar como um MVP para validar a proposta de valor e o interesse do público alvo em relação ao TableDEX, uma plataforma unificada focada na organização de ludotecas, gestão de cartas colecionáveis e engajamento da comunidade de jogos de tabuleiro.
